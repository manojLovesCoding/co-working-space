MongoDB Dummy Reservations

Documentation for generating simulated reservation and revenue records from May to October 2026.

1. Project Overview

This script generates 18 dummy reservation records in MongoDB, with 3 reservations per month from May 2026 to October 2026.

Purpose: Populate the Admin Dashboard with sample paid reservation data to test monthly revenue reports and analytics.
  • Total dummy reservations: 18
  • Months covered: May – October 2026
  • Reservations per month: 3
  • Payment status: Paid
  • Reservation status: Confirmed
  • GST rate: 18%

2. MongoDB Dummy Data Script

Follow these steps to execute the script:

  1. Open MongoDB Compass.
  2. Select your database.
  3. Open the reservations collection.
  4. Open the embedded MongoDB shell.
  5. Execute the following script.
JavaScript — MongoDB Shell
// DUMMY REVENUE DATA
// May 2026 - October 2026
// DO NOT RUN IN PRODUCTION

const userId = ObjectId("6a4a20eaf4141eadaa2a365d");

const collection = db.getCollection("reservations");

const monthlyData = [
  { month: 5, amounts: [2500, 4000, 5500] },
  { month: 6, amounts: [3200, 4800, 6500] },
  { month: 7, amounts: [1800, 5200, 7200] },
  { month: 8, amounts: [3500, 4500, 8000] },
  { month: 9, amounts: [2800, 6000, 7500] },
  { month: 10, amounts: [4200, 5500, 8500] }
];

const dummyBookings = [];

monthlyData.forEach(({ month, amounts }) => {
  amounts.forEach((amount, index) => {
    const day = [5, 14, 24][index];
    const year = 2026;

    const dateString =
      `${year}-${String(month).padStart(2, "0")}-${String(day).padStart(2, "0")}`;

    // Midnight IST = 18:30 UTC on the previous day.
    const startAt = new Date(
      Date.UTC(year, month - 1, day - 1, 18, 30)
    );

    const endAt = new Date(
      Date.UTC(year, month - 1, day, 18, 30)
    );

    const createdAt = new Date(
      Date.UTC(year, month - 1, day, 8, 30 + index)
    );

    const gstRate = 18;
    const taxableAmount = amount;

    const gstAmount = Number(
      (taxableAmount * gstRate / 100).toFixed(2)
    );

    const totalAmount = Number(
      (taxableAmount + gstAmount).toFixed(2)
    );

    const id = new ObjectId();
    const bookingId = `DUMMY-${id.toString().toUpperCase()}`;

    dummyBookings.push({
      _id: id,
      bookingId,
      user: userId,

      spaceName: "Team Leads Cubicle",
      bookingDate: dateString,
      plan: "daily",
      duration: 1,

      selectedSpaces: ["TLC01"],

      seatAssignments: [
        {
          spaceCode: "TLC01",
          assigneeType: "self",
          teamMember: null,
          name: "Dummy User",
          email: "dummy@example.com",
          phone: "0000000000"
        }
      ],

      invoiceType: "customer",

      billingDetails: {
        businessName: "",
        gstin: "",
        address: "",
        state: "",
        stateCode: ""
      },

      pricePerUnit: taxableAmount,
      subtotal: taxableAmount,
      discountAmount: 0,
      couponCode: null,

      taxableAmount,
      gstRate,
      gstAmount,
      totalAmount,

      startTime: null,
      endTime: null,

      startAt,
      endAt,

      razorpayOrderId: `dummy_order_${id.toString()}`,
      razorpayPaymentId: `dummy_payment_${id.toString()}`,

      paymentStatus: "Paid",
      status: "Confirmed",

      createdAt,
      updatedAt: createdAt,

      __v: 0,

      isDummy: true
    });
  });
});

// Insert all 18 records.
const result = collection.insertMany(dummyBookings);

print("Dummy bookings inserted successfully!");
print("Total inserted: " + Object.keys(result.insertedIds).length);

4. Important Precautions

Important: These are simulated paid bookings, not actual Razorpay transactions. Do not run this script in production.
  • Original November 2026 bookings are not modified.
  • The script only inserts new records.
  • All dummy records have Confirmed and Paid statuses.
  • Every record has a unique _id and bookingId.
  • Dummy payment references are generated for testing.
  • createdAt falls within the corresponding revenue month.
  • Every dummy record contains isDummy: true.
  • Check collection names and unique indexes before inserting.

5. Verify Inserted Records
